Self-healing

When a check fails, Pulse can try a first-response fix before alerting you. Fixes run through the gate on your Proxmox host, which only runs recipes defined there.

Loading…
OffNever run fixes. Alerts only.
Dry runLog what would run. Changes nothing.
Ask firstAlerts get a "Run fix" button.
AutomaticRun fixes, then tell you how it went.
Automatic mode: Pulse restarts services or Docker containers on your Proxmox host. It never touches Pulse itself, runs at most 10 fixes/hour, and you can stop everything with the kill switch at /etc/pulse-heal/enabled on the host.
Dry run: fixes are logged under Activity below — nothing is restarted. A safe way to see what Pulse would do.
