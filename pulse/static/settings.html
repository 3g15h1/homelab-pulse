Where alerts go

Webhook

Pulse POSTs JSON (title, message, severity, state, items, url) to this address. A Home Assistant webhook automation can turn it into a phone notification.

ntfy

Push to an ntfy topic; the ntfy app shows it on your phone.

Self-healing

When a check fails, Pulse can try a first-response fix before alerting you: restart the service or Docker container behind it, or run a recipe. Fixes run through the gate on your Proxmox host, which only runs recipes defined there. How recipes work
